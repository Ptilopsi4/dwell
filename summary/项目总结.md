# 项目总结（dwell）

## 项目概述
dwell 是一个常驻服务器的通用助手服务，基于 Node.js + TypeScript，通过飞书（Feishu/Lark）与人交流，具备命令审批、会话管理和 Web 管理面板能力。

## 文件结构

- **配置**
  - `package.json` / `package-lock.json` / `tsconfig.json`
  - `Dockerfile` / `docker-compose.yml`
  - `.env` / `.env.example` / `.gitignore`
  - `README.md`

- **源码（src/）**
  - `index.ts` — 入口
  - `harness.ts` — 核心执行框架
  - `sessions.ts` — 会话管理
  - `users.ts` — 用户管理
  - `state.ts` — 状态管理
  - `approval.ts`（ext/）— 命令审批机制
  - `channel.ts`（feishu/）— 飞书消息通道
  - `server.ts` + `panel.html`（web/）— Web 管理面板
  - `smoke.ts` — 冒烟测试

- **数据（data/ 与 data-local/）**
  - SQLite 数据库（dwell.sqlite 及 WAL/SHM 文件）
  - probe.sqlite、sessions.json、work/ 工作产物

- **状态（state/）** — `users.json`

- **测试（test/）** — `approval.test.ts`、`probe-watch.ts`

- **开发记录（.pi/）** — PLAN、TODO、REVIEW、gotchas 等文档及面板截图

## 技术栈
TypeScript、Node.js、SQLite、Docker、飞书开放平台 API、Web 前端面板
